Choerodon 重新登录说明

尚未确认当前 Choerodon 账号与 API 环境，请核对插件配置。

  1. 在本机终端确认 API 环境与插件配置的 C7N_API_URL 相同；需要切换时，先设置该环境变量。
  2. 运行 c7n login，在终端安全提示中输入该 Choerodon 环境的个人访问令牌（PAT）。不要把令牌写进命令参数或粘贴到本页面。
  3. 登录完成后，点击“刷新账号和项目”，核对显示的账号、租户及环境，再重新查询工作项。

加载失败也可能来自网络、API 配置或项目权限，请结合原错误核对。重新登录与刷新不会删除本地草稿或关联。
